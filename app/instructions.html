Installation and usage

Installation

  1. Install node.js v14.17.0 and npm v6.14.13
  2. Install gulp and the gulp command line utility
  3. Navigate to the root folder in terminal and run the following command
    npm install --save-dev && npx patch-package && gulp
  4. Update database if necessary using npx browserslist@latest --update-db
  5. Open gulpfile.js and change the projectPath and macroName variable names to match your project. This is not required. It is only to make it easier for you whe you run gulp buildLive

Usage

  • make edits to files in the /app folder only
  • add images & video to the /app/img folder
    • running gulp build will copy everything to the /dist folder compressing images, parsing sass and minifying+combining css/js in the process
  • the /dist folder contains your final project
  • Please use only _custom.scss and custom.js whenever possible

Gulp Commands

gulp build
  • creates a build in the /dist folder
  • will delete all files and folders other than the /img folder before running
  • this means that new images will be proccess but if you made any changes to existing images they will not be copied over. To reprocess all the images again use gulp rebuild
gulp rebuild
  • same as gulp build but deletes the /img folder first and copies all the images over
gulp buildLive
  • Creates a build that you can copy directly into blox. It will add the blox macro code to the top of the document from index-live.html.
  • Make sure you have set your projectPath and macroName in gulpfile.js or edit the index.html file in dist after running this.
gulp buildDirect
  • instead of proccessing and minifying js this just copys it. Usefull if you are getting js errors
gulp purge
  • use this as the last step after gulp build/rebuild if you want smaller css files
  • goes through the main.css file in /dist and removes all unused css
  • be careful when using this. It might sometimes remove css that you need.
  • in gulpfile.js under the purge function there is a whitelist where you can add css classes that you don't want to be removed
  • always check that the page is still working properly at all breakpoints and especially for classes that are added via javascript
gulp watch
  • watches for changes in html, css, js and image files then updates a browser preview whenever a file is saved
  • ctrl/cmd C in the command line to stop it
gulp
  • a shortcut for gulp build

Scrollytelling

Basic usage

There are many options for the the scrollytelling feature but the basic layout will look like this:

<div class="SA_scrollytelling-wrapper"> <div class="SA_scrollytelling-images"> <div class="SA_fullscreen-image"> Your first scrollytelling image/graphic goes here </div> <div class="SA_fullscreen-image"> Your second scrollytelling image/graphic goes here </div> </div> <div class="SA_scrollytelling-slide"> <div class="SA_scroll-text-wrapper"> <div class="SA_scroll-text"> <p>Your first scrollytelling text goes here</p> </div> </div> </div> <div class="SA_scrollytelling-slide"> <div class="SA_scroll-text-wrapper"> <div class="SA_scroll-text"> <p>Your second scrollytelling text goes here</p> </div> </div> </div> </div>

Functions inside main.js will automatically turn the above code into scrollytelling sections. You can have as many background images/graphics and slides as you want, however, the number of background images/graphics (.SA_fullscreen-image elements) should be the same as the number of slides (.SA_scrollytelling-slide).

It will automatically show the first image when you enter the first slide, the second image on the second slide and so on.

Scroll triggers

It is possible to run a javascript function when the user enters, exits or scrolls through the scrollytelling section.

This can be accomplished by adding data attributes to either the indidual slides .SA_scrollytelling-slide or the scrollytelling wrapper .SA_scrollytelling-wrapper.

data-on-enter="": Does something when the element enters

data-on-exit="": Does something when the element exits

data-on-progress="": Does something as the user scrolls. The variable response.progress gets the current scroll percentage (from 0 to 1)

Scroll trigger usage

The on-data- attributes accept the name of your JS function and any number of strings to pass to your function.

For example:

data-on-enter="changeColour, red"

And in your custom.js file

function changeColour(red){//do stuff}

Your first string must be the name of your funtion without parenthesis. After that you can pass any number of strings for your function seperated by commas i.e. (red, blue, a longer string, 1234).

You can only pass strings to your function. No variable, arrays or other functions. If you want to pass numbers you will have to pass it as a string then convert it to a number in your function using Number()

Scroll trigger example

<div class="SA_scrollytelling-slide" data-on-enter="changeSquareColour, red"> <div class="SA_scroll-text-wrapper"> <div class="SA_scroll-text"> <p>Slide text</p> </div> </div> </div>

How to add multiple slides for the same background

There will be cases where you may want to have multiple text boxes scroll over the same background. In that case you can do one of two things:

  1. Add more text elements to the same slide. <div class="SA_scrollytelling-slide"> <div class="SA_scroll-text-wrapper"> <div class="SA_scroll-text"> <p>Your first scrollytelling text goes here</p> </div> </div> <div class="SA_scroll-text-wrapper"> <div class="SA_scroll-text"> <p>Your second scrollytelling text goes here</p> </div> </div> </div>
  2. Add multiple images with the same image <div class="SA_scrollytelling-images"> <div class="SA_fullscreen-image"> <img src="image.jpg"> </div> <div class="SA_fullscreen-image"> <img src="image.jpg"> </div> </div>

Align text left or right

To move the text box add the class .SA_scroll-text--left or .SA_scroll-text--right to .SA_scroll-text

<div class="SA_scrollytelling-slide"> <div class="SA_scroll-text-wrapper"> <div class="SA_scroll-text SA_scroll-text--right"> <p>Your right aligned text here</p> </div> </div> </div>

Single background scrollytelling

You may want to just have one element in the background (like a d3.js chart) that you change with javascript as the user scrolls using the data-on- attributes.

For that to work just add the .SA_scrollytelling-wrapper--single-bg class to .SA_scrollytelling-wrapper and add the background image/chart as the only .SA_fullscreen-image element.

Single background scrollytelling example

If you want just a single background that you can change on each slide with js add the class .SA_scrollytelling-wrapper--single-bg to .SA_scrollytelling-wrapper. Then you shoul add only one div with the class .SA_fullscreen-image

If you dont want the slide to fade in at the start and out at the end add .SA_scrollytelling-wrapper--scroll-in to .SA_scrollytelling-wrapper

To change the background slide when a slide enters add data-on-enter="YOUR JS FUNCTION NAME HERE" to the .SA_scrollytelling-slide element. In this case it turns green on enter

You can also use data-on-exit to do stuff when the slide leaves the screen. In this case it turns purple

You can also do stuff on progress with data-on-progress. Use the response.progress variable to get the current scroll percentage (from 0 to 1)

Layout and typograhy

Images

  • Use the picture tag below for images. This ensures that the image will lazyload and that the proper size/compression will be used.
    Replace all three instances of YOUR-IMAGE-NAME with your image name but leave the file extension. If you want to use a differnt file extension change both instances of jpg and remember to change type="image/jpeg" as well.
    <picture> <source data-src="images/YOUR-IMAGE-NAME.webp" type="image/webp" /> <source data-src="images/YOUR-IMAGE-NAME.jpg" type="image/jpeg" /> <img loading="lazy" data-src="images/YOUR-IMAGE-NAME.jpg" alt="Alt tag" /> </picture>
  • Use the highest quality image availible. The image will be compressed automatically.
  • Any jpg or png placed in the /images folder will be compressed and exported at various widths (2480px, 1920px, 1280px, 1024px, 860px, 540px and 320px). Each image in the dist folder will have the width appended to the filename. Example: milliken-park-320w.jpg is 320px wide.
  • You can put non-image files in the /images folder. They will be copied over without compression

Image zoom and animation

  • There are several classes you can add to your img tag:
    • : Clicking on the image will zoom in
    • SA_animate: Plays an animation when the image comes into view. Must be combined with another class to pick the animation type. Predefined options are: SA_fadeIn, SA_slideInLeft, SA_slideInRight, SA_blurIn, SA_grow or you can make your own. Any element with SA_animate will get the class SA_active when it comes into view. You can use this to create your own animations.

Updating Node, NPM and packages

It is not currently recommended to update node, npm or any of the gulp packages as this can break some dependacies (Currently autoprefixer v 10.0.0 doesn't work)
If you still want to update your packages use npm install -g npm-check-updates to install, then npm-check-updates to check if your dependencies have updates, and npm-check-updates -u to update your package.json versions. Then it's just npm install and it will download new versions.
